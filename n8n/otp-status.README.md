# OTP → статус кода

[Все сценарии](README.md) · [JSON для импорта](otp-status.json)

Импортируйте JSON, настройте Header Auth входящего вебхука и Header Auth с ключом OTP-проекта (`otp:read`) у **WAIX API**. Дополнительные параметры в WAIX settings не нужны.

Ваш сервер вызывает POST на URL этого сценария:

```json
{"id":"f5bf0474-d4b6-4ca5-bd1b-92e44f3ad0fb"}
```

Сценарий проверяет UUID и выполняет `GET /api/v1/otp/{id}`. ID должен принадлежать текущей сессии пользователя и проекту ключа. Проверьте это на своём backend до вызова. Не разрешайте посетителю перебирать чужие ID.

`sent` / `delivered` / `read` говорят об отправке кода. Доступ пользователю выдаётся только после успешного `otp/verify`. При `expired` начинайте новую попытку входа по явному действию пользователя. Ограничьте polling; не проверяйте статус каждую долю секунды.

Ошибки ввода — 400, отсутствие заявки — 404, сетевой сбой — 502. История отключена, ответы не кешируются, sandbox test_code в них не попадает.
