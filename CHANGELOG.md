# Изменения

## 0.2.0

- n8n: отдельные настройки, строгая проверка входа, статус OTP, ответы при обрыве/таймауте, Retry-After и request ID, очистка sandbox-кода. Все пять сценариев исполняются в тестовой n8n 2.40.5.
- Bitrix24: серверный receiver и worker, постоянная очередь SQLite, проверка портала и токена, согласие контакта, дедупликация, фиксированный запрос при повторе и ограничение попыток.
- 1С: шаблоны с несколькими переменными, нормализация телефонов, OTP send/verify/status, статус сообщения, структурированные ошибки.
- Make: шесть запросов, mapping полей, Data store и маршруты ошибок.
- Zapier: готовый Code-шаг для пяти операций с проверкой данных и JSON-сериализацией.
- Инструкции на русском: установка, проверка перед запуском, работа с ошибками и границы каждого подключения.
