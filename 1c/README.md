# WhatsApp API для 1С

`WAIX.bsl` — пример серверного общего модуля для 1С:Предприятия 8.3 с поддержкой JSON и HTTPS. Он отправляет одобренный шаблон с одной переменной тела. Это исходный код для интегратора, не универсальное расширение `.cfe`: точку вызова, права и регистр уведомлений нужно добавить в вашей конфигурации.

1. Подключите номер в WAIX, получите Connection ID и серверный ключ `messages:write`.
2. Создайте и одобрите шаблон с одной переменной. Укажите точное имя и язык.
3. В обработчике бизнес-события запишите уведомление в отдельный регистр: документ, получатель, согласие WhatsApp, UUID операции, параметры, состояние. Не выполняйте сетевой запрос внутри транзакции проведения документа.
4. Фоновое/регламентное задание вызывает `ОтправитьШаблонWAIX` для записи регистра. UUID создаётся один раз при записи события. Сохраните ответ `data.id`, HTTP-код и request_id; не записывайте ключ или полное тело сообщения в общий журнал.
5. 202: сообщение в очереди. 400/401/403: исправьте параметры/ключ/права. 429: дождитесь Retry-After. Сетевой сбой: повтор с тем же UUID и неизменными параметрами, после проверки состояния.
6. Вебхуки подписаны HMAC. Принимайте их через серверный обработчик с проверкой подписи, либо используйте журнал/GET `/api/v1/messages/{id}` для проверки статуса.

Проверка на конкретной конфигурации 1С обязательна: в этом репозитории нет лицензированной среды 1С для исполнения BSL. TLS использует доверенные сертификаты ОС; не отключайте проверку сертификата.

Официальные материалы: [JSON в 1С](https://v8.1c.ru/platforma/json/), [пример HTTPS с хранилищем сертификатов ОС](https://v8.1c.ru/metod/article/rabota-1s-dokumentooborota-s-novoy-versiey-veb-servisa-morfer.htm).
