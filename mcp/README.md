# WAIX MCP — WhatsApp API в ИИ-ассистенте

Удалённый сервер: **https://waix.kz/api/v1/mcp**. Транспорт — Streamable HTTP, вход — OAuth с PKCE S256. Отдельную программу или npm-пакет устанавливать не нужно.

## Подключение

1. Откройте настройки MCP в Cursor и добавьте сервер по URL. Для конфигурации `.cursor/mcp.json` проекта или `~/.cursor/mcp.json` используйте [cursor.json](cursor.json).
2. Начните авторизацию. В открывшемся окне войдите в WAIX, проверьте компанию и адрес возврата в приложение.
3. Выберите права: чтение; подготовка сообщений; тестирование OTP в выбранном Sandbox-проекте. Необязательные права можно снять.
4. Подтвердите подключение. Попробуйте: «Покажи мои номера WhatsApp» или «Найди инструкцию по шаблонам WAIX».

Для других клиентов нужна поддержка удалённого MCP, OAuth, PKCE S256 и Dynamic Client Registration. Работа с официальным TypeScript SDK проверяется автоматически; интерфейс и совместимость отдельных клиентских приложений могут отличаться.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `waix_search_docs` | Ищет статьи по публичной документации |
| `waix_read_docs` | Читает статью по slug |
| `waix_list_connections` | Показывает номера и состояние подключения |
| `waix_list_templates` | Показывает до 200 шаблонов выбранного номера |
| `waix_message_status` | Возвращает статус и коды ошибок без тела сообщения |
| `waix_prepare_template_message` | Готовит **одно** сообщение, но не отправляет его |
| `waix_action_status` | Проверяет заявку на отправку |
| `waix_otp_sandbox_send` | Создаёт тестовый OTP, не отправляя его в WhatsApp |
| `waix_otp_sandbox_verify` | Проверяет тестовый код |
| `waix_otp_sandbox_status` | Показывает статус тестового запроса |

Статьи также доступны как resources: `waix://docs/{slug}`. Список инструментов зависит от выданных прав.

## Как отправить сообщение

Укажите Connection ID, получателя в международном формате (`+77071234567`), имя и язык одобренного шаблона, значения переменных. Поддерживаются текстовые шаблоны с числовыми переменными, без медиа и кнопок. Авторизационные шаблоны отправляйте через OTP API.

Ассистент вернёт `approval_url`. Откройте ссылку, проверьте получателя и полный текст, подтвердите отправку в WAIX. Ссылка действует 10 минут. Подтвердить может только пользователь, подключивший приложение, в той же компании. Согласия в чате недостаточно.

Действуют обычная подписка WAIX и тарифы Meta. Повторное подтверждение одной заявки не создаёт второе сообщение. `sent` у заявки означает очередь, а не доставку: далее используйте `waix_message_status`. После сетевого сбоя откройте прежнюю заявку и обновите статус; при необходимости повторите её подтверждение через минуту.

## OTP и права

OTP работает только в Sandbox: тестовый код, проверка, статус. `test_code` нельзя использовать для реальной авторизации. Рабочие OTP и платные отправки через эти инструменты недоступны. `idempotency_key` — UUID, сохраняемый для одного логического тестового запроса.

Доступ выдают Owner/Admin/Developer. Он действует до 90 дней. Access token живёт 15 минут; refresh token меняется при использовании и действует до 30 дней в пределах срока подключения. Повторный обмен старого refresh token отзывает подключение. В кабинете **MCP** можно отключить приложение; Owner/Admin также могут отзывать подключения коллег.

## Ошибки

- `401`: подключитесь заново. Возможны отзыв доступа, истечение токена, изменение роли или отключение Sandbox-проекта.
- Нет инструмента: не выданы соответствующие права. Переподключитесь и разрешите нужный scope.
- `402` при подтверждении сообщения: нужна действующая подписка WAIX API.
- `409`: заявка уже обрабатывается или шаблон изменён; обновите статус. При изменении шаблона подготовьте новую заявку.
- `429`: дождитесь `Retry-After`. До 120 MCP-запросов в минуту на подключение, также действуют лимиты API/OTP.

При обращении в поддержку передайте `request_id`, без токенов и кодов.

## Протокол

Стабильный протокол `2025-11-25` с согласованием версии. JSON-RPC через POST, без транспортных сессий и фонового SSE. `GET` и `DELETE` ресурса возвращают `405` после проверки авторизации.

- Resource metadata: `https://waix.kz/.well-known/oauth-protected-resource/api/v1/mcp`
- Authorization server metadata: `https://waix.kz/.well-known/oauth-authorization-server`
- Public client: `token_endpoint_auth_method=none`
- Grant: authorization code, PKCE S256; refresh token с ротацией
- `resource=https://waix.kz/api/v1/mcp` обязателен в authorize и token
- Redirect URI должен точно совпадать с зарегистрированным. HTTP разрешён только для localhost/loopback.
- MCP Bearer не является ключом API v1; обычный ключ WAIX не принимается в MCP.
